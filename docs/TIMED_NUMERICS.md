# 原生计时输出的独立数值验证

对原L1/L2/L3配置`numerical_validation = true`时，原生性能路径现在自动逐次执行独立CPU FP64数值门；不要求另配`input_calibration`。这是软件实现，未运行设备或模型实验。

## 调用顺序与预算

同步墙钟样本仍只包含原来的调用、输出消费及完成屏障。输入生成、真值计算、输出搬回CPU、数值比较和收据写入均在该区间之外；不把FP64诊断时间替换为性能样本。

每次验证先读取参考**本次调用前**的状态，在实际输入尺寸、存储值、dtype和RNG下准备独立真值，恢复RNG后再调用参考和比较。L1使用显式公式，L2使用冻结复合算式，L3使用冻结逐层/模型算法。参考和候选接受相同的RMS与所有元素门；结构、shape、dtype、整数/bool、NaN及正负Inf也要匹配。不通过、超内存估计额度或缺少检查不能返回正结果。

未配置校准文件时采用当前来源绑定规格中的初始精度政策；配置值校准时使用该记录的更严格政策。配置[精度阈值校准](PRECISION_CALIBRATION.md)时采用在原上限内拟合并冻结的政策，校准/执行设备身份分别核对；同类设备复用仍须逐次参考自资格。没有自动放宽误差、缩小尺寸或改动隐藏输入。原FP32非组合基线只有未启用数值验证时才保留原TF32设置；数值验证要求完整FP32精度。

`oracle_memory_mb`仍是主机增量内存的估计准入额度，不是RSS硬限制。预热与计时的每个输出都要通过独立验证，真实主机/设备总开销可能明显增加；本次没有测量这些开销。

## 显存读数与验证边界

原生显存探针在同一次实际前向后验证输出，不另加候选前向。输入在调用前按整个组隔离，避免候选原地修改污染参考。候选与参考均为no_grad，并按调用前Torch RNG验证；共享控制在成功或异常后保留候选实际调用后的CPU/CUDA/Neuron状态，也保留当时的Python/NumPy状态。

显存报告是该进程Torch CUDA allocator的绝对峰值。验证输入副本即使在重置峰值前分配，也会留在活跃基线；因此先记录副本分配前后增量，再读取原始peak，返回`peak_bytes = raw_peak_bytes - verification_input_bytes`。副本保持存活至候选结束，参考/FP64验证和输出摘要在读数后执行。保留原始峰值及调整量，不把预分配直接当成已排除；负增量、无效读数或验证失败拒绝结果。原生内存收据绑定输入seed/签名、验证状态和三项字节读数；来源重放逐项核对。此读数包含调用前已存活的其他allocator分配，不是进程RSS或独占物理显存认证。

## 首次、预热与正式样本

原生基线记录至少一份`first`检查，随后记录3次预热和`num_perf_trials`次正式调用的`timing`检查。候选性能路径还核对实际首次冷调用的`first`输出，以及3次预热和全部正式调用；原生标准/隐藏双向正确性调用也使用调用前票据。配对路径要求每轮三方输出均通过，至少`(paired_trials + 3) * 3`份`timing`检查。CUDA候选性能路径还要求一份独立`memory`检查，对应实际峰值显存前向；基线、配对和没有该探针的Neuron路径不虚构此项。首次、计时、显存和正确性控制的类别分开核对；用额外正确性控制替代缺失的计时检查不能通过覆盖门。

配对时每轮只准备一次参考调用前真值，再让参考、候选和控制共享同一输入、前向RNG和预状态。三份输出分别接受门；验证过程不额外调用参考，不额外推进普通Tensor状态、buffer或随机序列。Neuron的标准双向调用、首次/预热/性能和配对路径使用同一入口。验证抛错时，计时器也在`finally`恢复候选实际调用后的CPU/CUDA/Neuron RNG。

## 逐次证据与恢复

`metadata.timed_numerical_audit`保存评测器/参考/规格/可选输入配方摘要、精度政策、内存额度、阶段需求，以及逐输出序号、类别、输入签名、数值门、参考信号和程序/原生mask收据。序号不是随机种子；记录明确使用实际RNG重放，不从序号虚构seed。

评分与恢复重新核对政策、首调用、计时及适用的显存覆盖数、原生尺寸/状态票据、RMS限制、误差计数、信号和图/模型收据。删除输出、重封摘要后改类别、扩大预算、修改误差计数或删掉程序证据均不能取得资格。基线缓存、候选恢复、最终重测、配对分析与普通评分都使用这条检查；失败样本继续留在原分母。

不运行性能的隐藏/诊断/小实例阶段没有虚构计时检查数；实际正确性仍由原独立诊断控制与严格契约验证。profiling不是性能计分来源。未启用`numerical_validation`的旧路径保留原比较政策。

实现见[逐次控制](../kb_workflows/evaluation/timed_numerics.py)、[共享票据](../kb_workflows/numerics/input_calibration.py)、[配对计时](../kb_workflows/evaluation/paired_task.py)和[CPU回归](../tests/evaluation/test_timed_numerics.py)。这不是执行来源认证或防候选篡改的通用安全证明。参考专用阈值拟合代码已实现，见[阈值校准](PRECISION_CALIBRATION.md)；不能将初始预算或这些软件回归写成设备阈值已校准。
