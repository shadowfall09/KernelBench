# 原L1/L2/L3的隐藏输入族

当前默认隐藏协议在原隐藏文件和既有压力测试之外，为原L1全部100题追加算子专用实例。它采用参考**实际初始化后的参数和属性**，只改变合法正确性输入；不调用或替换名义`get_inputs`，不修改模型初始化、权重形状或计时尺寸。

原L2全部100题和L3全部50题也有来源绑定的输入族。三个level共250题每种子追加1,529例：L1为632，L2为600，L3为297。原有隐藏实例仍运行，98和100题的旧值变换则通过显式任务修订修正角色语义。

100题每个种子共632个新增实例，默认42、123、456三个种子。最终冻结若声明私有种子，则逐例重放同一组私有种子。每题基本族为奇数形状、另一合法形状、非连续布局、近常量、动态范围和边界输入，适用题另加抵消、并列极值或声明的非有限值。它们不进入开发反馈，也不用于挑选更快候选。

## 算子约束

| 家族 | 保留的约束与新增检查 |
| --- | --- |
| 矩阵1–18 | 乘法耦合轴、向量/标量、batch、对角/对称/三角及转置角色；长K、短K、奇数维度、抵消和非连续切片。输入标量可变，模型参数不变。 |
| 激活19–32、88 | 精确/近似激活语义和实际参数，2D/3D形状、正负值、近常量及动态范围。 |
| 归一化33–40 | BN/IN/GN实际通道、组数和模式；LayerNorm保留完整normalized_shape，只改变外部batch。无epsilon的范数避免全零分母。 |
| 池化41–46 | 依据实际kernel/stride/padding/dilation/ceil-mode构造合法空间范围；并列最大值和返回索引使用原参数，不为测试切换return_indices。 |
| 归约47–49、51–53 | 保留声明轴和keepdim语义，另有sum/mean抵消、首个并列arg索引及末端极值。 |
| 卷积50、54–87 | 使用真实首个卷积的输入通道、kernel/stride/padding/dilation/output padding及分组；构造合法标准/转置卷积空间维度，保留方形/非方形族。 |
| 扫描89–93 | 保留真实扫描轴及bool mask。乘积使用随机有界二次幂前缀，mask包含全关/全开行；既有五类扫描隐藏实例也保留。 |
| 损失94–96、98–100 | 类别索引、ignore_index、概率、非负target、triplet参数和±1标签分别处理；KL包含合法零target。 |
| Attention97 | Q/K头维耦合、K/V序列耦合、非因果/无mask/零dropout语义不变；覆盖不同Q/K长度、V宽度及单query。 |

第100题仍采用冻结参考的1D标签广播和方形预测/标签耦合；只修正旧D2/D3/D4，使其仅缩放预测值，标签保持±1，第五个结构化标签实例保留。第98题旧D2/D3改为正温度的log概率变换并逐行归一化，三个原实例槽位保留。两题参考公式、原名义工厂与计时输入均未修改，修订表记录旧/新隐藏SHA与原因。其他旧实例原字节保留。见[输入契约修订](REFERENCE_REVISIONS.md)。

## L2/L3的耦合尺寸

[冻结清单](../kb_workflows/model_input_families.json)记录150题原输入工厂的名义shape、参考SHA、逐族shape与约束说明；只使用参考元数据和人工审查的尺寸角色，不按数值输出、候选或性能筛选输入。运行时不替换构造函数，也不执行原名义工厂来分配巨型隐藏输入。CLI和收据复核读取清单，无需导入Torch。

| 家族 | 形状与角色 |
| --- | --- |
| L2矩阵融合 | batch为3/5，输入/输出特征随初始化固定，外部同形状张量保持batch耦合。 |
| L2卷积融合 | batch和合法奇数空间维度变化，通道/kernel/stride等初始化不变；3和34题保留LayerNorm实际归一化的末轴宽度。26题外部残差形状由转置卷积输出公式确定。 |
| L3 MLP/CNN/视觉块 | batch变化，保留固定分类器、位置/窗口及其他构造依赖维度；不把任意图像尺寸当作合法输入。 |
| L3/34 RNN、35–38 LSTM、39–42 GRU | 区分sequence-first和batch-first，序列长度17/31，输入与h0/c0的batch轴同步变化；层数、方向和隐藏宽度固定。 |
| L3/43、44、50 attention | batch和序列长度变化，保留嵌入/头维，长度不超过初始化的因果mask容量。 |
| L3/46–47 NetVLAD | batch和描述符数量变化，特征、聚类及ghost-cluster维度固定。 |
| L3/33固定状态RNN | 普通属性hidden在构造时固定batch，保留实际batch和特征，不更换状态来接受缩小输入。 |
| L3/48–49 Mamba | A/B/C参数固定batch、序列和head；保留声明的d_head与block_len，不借broadcast缩题。 |

前三个固定形状任务用`fixed_shape`及明确原因代替不合法的奇数/另形状族；仍追加非连续、近常量、动态范围与边界值，共五族。其余147题每题六族。这里的布局和值变化尚不能替代针对各复合/序列算法的全部饱和、抵消、极值与存储别名反例；R-06仍为部分实现。

全部150题真实初始化与原工厂在meta设备检查，不执行数值模型实验。meta只能证明该版本Torch的元数据路径接受这些形状；不证明数值正确、后端支持或参考资格。L3尚无独立数值适配；L2启用`numerical_validation`时，这些实际输入也进入独立FP64控制，失败保持失败。

## 非有限值和参考自资格

只有19、20、21、22、28五题在本版明确扩展了非有限值域，增加混合NaN/±Inf/有限值及全NaN实例。其精确传播经过三种存储dtype的CPU对照；其他题不套通用NaN/Inf变换。源文件身份不变，域扩展属于当前显式评测协议。

原生比较继续严格核对NaN位置和Inf符号。独立FP64门对全非有限输出记录`nonfinite_only`：结构、dtype及传播匹配仍须通过，RMS、误差和限值为`null`，不编造零误差。该实例不贡献参考信号；整个任务仍须有信息量足够的实际实例。有限真值与非有限参考不匹配时依旧失败，不能把溢出变成这种豁免。

新增固定近常量CPU FP32案例显示，BatchNorm和InstanceNorm参考自身也可能超过已公布的FP64预算。目录保留这一已知问题和负例，不放宽阈值、不删除案例，也不推断其他设备的误差分布。没有开启独立数值复核时，原生比较的语义仍是与参考一致；启用时参考自身失格会阻止资格。

## 实际布局与内存

新增非连续实例使用正stride切片。dtype或设备转换可能压紧切片，因此原生输入转换现在在必要时通过`empty_strided`复制，保留实际shape/stride和离散dtype；后续隔离副本也保留正stride。这里没有宣称任意storage offset、重叠或负stride布局都已覆盖。

`input_family_memory_mb`默认256 MiB，可放在`[run]`或通过`--input-family-memory-mb`设置。它按每例全部输入元素的16倍字节估计生成临时量与切片存储，在任何该例输入分配前准入。该估计不包括已存在模型参数、候选workspace或独立oracle，不是OS内存硬限；独立FP64复核仍有自己的`oracle_memory_mb`。

如果真实固定维度超出包络，任务明确失败/缺完整证据；不缩小normalized_shape、不跳过该例，不因此通过。整个请求仍受原墙钟超时约束。

L3/48–49的固定输入按当前估算各需2,048 MiB，默认256 MiB会拒绝；需要显式更大`input_family_memory_mb`才可分配。该输入额度仍不包含模型和workspace，不表示设备有足够显存。当前实现工作没有实际分配或运行这些模型输入。

## 请求、证据和恢复

请求的`operator_inputs`绑定协议、参考SHA、算子族、完整标签及内存政策，L2/L3还绑定完整家族清单哈希和固定形状原因。CLI、生成、Harbor导出和worker在设备/模型调用前核对来源；CLI的`--dry-run`显示覆盖题数且不导入设备SDK。

真正隐藏执行后，`metadata.operator_inputs`保存逐案例/种子、有效输入签名、内存估计和通过情况；每条还必须对应原生`reliability_checks`中的实际双向调用、相同种子与有效布局。评分和恢复重新核对完整集合，缺例、重复调用标签、错误布局、改seed、超内存或空stride等不能只改“passed”摘要获得资格。新的评测器和内存选项进入冻结、实验/研究/RL契约；旧通过结果不能直接沿用。

L2/L3独立重建预期逐输入shape、输入数量与原生精度。即使同时更改摘要和原生调用记录、重新计算内存字节，合法尺寸被缩小或dtype被替换也会拒绝。

追加案例由独立的`kernelbench_pro_operator_cases_v1`协议标识；98/100旧分布语义变化另有revision 2记录，先前扫描修订保持原样。校准名义值配方不套用这些案例，隐藏失败也不反馈给同轮候选优化。

实现与CPU/模拟证据见[L1输入构造](../kb_workflows/operator_cases.py)、[L2/L3输入构造](../kb_workflows/model_input_cases.py)、[覆盖复核](../kb_workflows/operator_input_policy.py)、[L1回归](../tests/test_operator_inputs.py)及[模型家族回归](../tests/test_model_input_cases.py)。250题真实初始化只做meta元数据检查；数值和原生入口以CPU小配置/小输入及显式Neuron模拟器验证。这不等同于原尺寸、GPU、Trainium或预训练模型实验。
