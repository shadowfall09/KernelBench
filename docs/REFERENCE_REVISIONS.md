# 参考修正与输入契约版本

参考和隐藏输入的修正通过[修订表](../kb_workflows/benchmarks/reference_revisions.json)记录前后SHA-256、任务版本、原因、代码证据与依赖。原始档案保留；修正后的结果不能沿用旧参考的通过记录。当前有L1/89–93、98、100七条revision 2记录。

## 概率和浮点标签的旧隐藏变换

L1/98名义输入声明为逐行概率分布，旧D2/D3同时乘3或0.01后不再归一化。当前使用`softmax(log(p) * temperature)`改变浓度，正预测、非负target和单位质量保持；D1及三个实例槽位保留，负温度不在声明域内。

L1/100的标签虽以float存储，语义仍为±1。旧D2/D3同时缩放标签，破坏域；D4同时取反预测与标签，其乘积不变。当前仅变换预测，五个实例槽位和结构化标签检查保留。参考的1D标签广播公式没有修正为另一种损失。

两项只修订隐藏语义，参考前后SHA相同。生成脚本同步维护角色与结构化实例，防止重新生成时退回旧变换。修订与收据以新评测器为准，不将旧实验结果重标为新规则通过。

## 第92题：沿正确轴计算exclusive cumsum

旧代码沿`dim`拼接零，再用`[:-1]`裁剪第0维。当前初始化`dim=1`，因此旧输出shape与exclusive scan题义不一致。

修正版在声明轴前补零，累加后沿同一轴裁回输入长度。负轴、单元素扫描与空扫描轴也保留输入shape，整数/bool遵循Torch cumsum的dtype提升。独立FP64公式采用“先inclusive sum，再移位”的不同实现。旧轴裁剪公式继续作为反例，不能满足修正后的参考资格。

原题的初始化参数和名义计时输入尺寸没有缩小。旧完整源码可从修订表的`last_legacy_commit`恢复；历史内容不复制到运行题目目录作为第二套默认参考。

## 五类扫描的合法隐藏输入

[扫描输入族](../kb_workflows/scan_cases.py)覆盖89 cumsum、90 cumprod、91 reverse cumsum、92 exclusive cumsum与93 masked cumsum。每题保留已有隐藏分布，再追加：

| 实例 | 检查 |
| --- | --- |
| 奇数尺寸 | axis 1上的非整齐长度及边界索引 |
| 非连续布局 | 切片输入；masked scan的bool mask也保留非连续stride |
| 三维输入 | 在同一合法axis 1上扫描，避免把二维线性地址假设成题义 |
| 单元素轴 | inclusive/exclusive及mask的边界结果 |
| 空扫描轴 | shape、dtype与空输出契约 |

cumprod实例使用接近单位量级的有限输入，并在首位置加入负号，使短扫描输出保持信息量。mask使用bool，包含全关、全开及混合行，不被浮点缩放。实例只由指定种子构造，不读取候选输出或性能。隐藏阶段沿用各阶段的原生种子，开发反馈不包含这些额外输入。

第90题原文件有3种保留分布，其余四题各有4种；本次分别追加5例，不把此前过滤的分布伪装成已保留。生成脚本也保留追加入口。实际运行旧大尺寸实例、GPU或模型实验均未进行。

## 空输出与未知测量

合法空Tensor须符合shape、dtype及容器结构，不能凭空增加或省略元素。浮点数值收据标记`empty_tensor`，元素数为0，RMS、最大误差和误差限值保留`null`，不写成测得零误差。

空输出本身没有信息量，不能单独满足`reference_signal`；同一验证范围仍须有非空且信息量足够的实例。全部非有限输出也不会借空输出规则获得数值资格。原生性能输入未因空边界案例而改变，隐藏诊断时间不进入性能采样。

## 修订如何进入工作流

统一payload为这些任务携带`eval_config.reference_revision`，含当前修订ID、版本、参考/隐藏源码SHA、修订表SHA和共享隐藏生成器SHA。worker和HTTP队列在执行前核对；数字类型伪装、旧源码、缺失或改动的修订、隐藏文件或共享依赖不一致都会被拒绝。

本地、Docker、Modal、队列和Harbor共用原生dispatch；基线、标准/隐藏、配对、最终重测及诊断结果记录当前修订。评分和恢复重新核对该记录。匹配的负结果仍可保留以避免反复花费，缺失修订的正结果不能作为新版本通过。实现见[修订绑定](../kb_workflows/benchmarks/reference_revisions.py)。这不是任意代码安全或硬件来源认证。

KernelBench-105运行清单升级为version 2，保留250个任务、105 scored、5 probe、140 extended、原seed、层标签和选题角色。`selection_reference_snapshot`保存原始选题快照，当前快照明确表示“基底加已声明修订”；完整题集报告也带修订表版本信息。研究档案CSV与来源表保持原字节，不把旧分析结果重标为修正后的实验。

参考、隐藏源码、共享依赖、修订表和评测模块进入内容指纹。旧基线、最终重测与评分证据需要按新规则重新验证；程序不会在这次代码维护中自动启动实验。保留候选的重评分流程见[隔离与重评分](ISOLATION_REGRADE.md)。

## 诊断选项的统一契约

状态检查、独立数值检查、主机oracle内存额度，以及Sanitizer和重复设置，使用同一份诊断选项列表进入原生payload、生成协议、最终冻结、研究导出和运行分组。改变其中一项不能沿用旧冻结记录或与不同检查条件的运行混排。这修正了早期新增状态/数值开关后部分摘要仍仅记录Sanitizer和重复检查的遗漏。

原250题均有来源绑定的附加输入族，覆盖范围与固定尺寸例外见[隐藏输入](OPERATOR_INPUTS.md)。更细的算子反例、L2/L3输入校准、L3独立数值与完整基线仍在R-04/05/06/13中继续实现；形状覆盖不等于所有数值门已完成。
